# 深圳共享单车潜在需求缺口与情景化减碳潜力

2026 年（第十二届）全国大学生统计建模大赛参赛研究整理。项目以深圳市共享单车订单流和城市 POI 为基础，在 H3 网格—小时尺度上依次分析**订单与供给状态代理、城市功能关联、预测差额代理和情景化减碳潜力**。[阅读全文、图表与公式](https://chengyun249.github.io/bikeshare-demand-carbon-shenzhen/paper/article.html)；[研究导读](docs/research_guide.md)梳理模型机制、流程图和代码入口。

> **解释边界：**“供给富裕 / 紧张”不是真实车辆库存；“潜在需求缺口”是模型预测值高于已实现订单的正差额，不是已证实的未成交需求；减碳数字是参数情景下的潜力估算，不是核证减排量。

## 研究路径

```text
公开订单接口 + 高德 POI
        ↓ 时间、坐标清洗与 H3 网格—小时聚合
出发 / 到达 / 净流入 → 隐含库存与供给状态代理
        ↓
POI 与订单强度：Poisson 对照 → 负二项计数模型
POI 与供给代理：L2 正则化 Logistic 辅助分析
        ↓
历史均值 / HistGradientBoosting / 随机森林对照
        ↓ 预测值 − 实际订单的正差额
潜在需求缺口代理 → 需求实现比例与出行替代情景 → 净减碳潜力
```

### 1. 从订单流构建供给代理

订单起终点映射到 H3 网格，按小时计算出发、到达和净流入。以网格基础供给水平加日内累计净流入构造隐含库存代理，再用分位数规则标记相对供给富裕与紧张的网格—小时。该指标只能帮助寻找值得核查的区域，不能替代车辆实时位置或可用数量。

### 2. 用 POI 解释空间差异

将居住、办公、商业、地铁、公交等 POI 聚合到网格。订单数是过度离散的计数变量，因此比较 Poisson 与负二项模型，并以负二项模型描述 POI 与订单强度的条件关联。L2 正则化 Logistic 用于辅助分析 POI 与供给代理的关系；这些系数和 AUC 不构成因果证据。

### 3. 预测差额与减碳情景

按日期划分训练期（2021-08-20 至 08-26）与测试期（08-27 至 08-28），比较历史网格—小时均值、HistGradientBoosting 与随机森林。论文文字称以随机森林预测正差额构造缺口；**提交脚本实际采用 HistGradientBoosting 输出计算缺口与后续碳情景**。碳情景再设定需求实现比例、出行方式替代和调度排放，计算净减碳潜力。**预测特征包含同一小时的到达量与由出发量参与构成的净流入量，因此测试误差不能解释为部署时的前瞻预测能力**；详见[研究导读](docs/research_guide.md)及[方法与结果核对](docs/method_notes.md)。

## 论文与交付结果

| 项目 | 结果与口径 |
| --- | --- |
| 主分析样本 | 2021-08-20 至 08-28，共 9 天；清洗后订单 **13,915,910** 单，活跃 H3 网格 **2,854** 个，网格—小时面板 **616,464** 行 |
| 订单强度模型 | Poisson 的 Pearson χ²/df 约 **5.35**；负二项 AIC **2,250,013.50**，低于 Poisson 的 **3,599,460.35** |
| 供给代理辅助模型 | 富裕代理 ROC-AUC **0.846**；紧张代理 ROC-AUC **0.655** |
| 订单预测测试集 | 历史均值 RMSE **29.52**，HistGradientBoosting **17.13**，随机森林 **14.86**；解释限制见上文 |
| 1.10 km 基准距离下的净减碳潜力 | 保守 **3.98**、中性 **18.01**、积极 **41.76** 吨 CO₂，均为情景估算 |

图示：[测试集 RMSE 对比](https://chengyun249.github.io/bikeshare-demand-carbon-shenzhen/figures/fig_stage4_model_rmse.png)、[不同情景的减碳潜力](https://chengyun249.github.io/bikeshare-demand-carbon-shenzhen/figures/fig_stage5_scenario_carbon_comparison.png)。

## 研究范围

- 9 天样本难以检验季节、天气、节假日与长期调度变化。
- 同时刻特征的使用使测试 RMSE 可能偏乐观，预测正差额不能直接识别真实未满足需求。
- 减碳估算依赖新增骑行实现比例、替代交通方式、平均距离和调度排放假设；不能作为实际减排或碳核证依据。

这是团队参赛研究的公开整理版。赛事信息见[大赛官网](https://www.ai-learning.net/dstz/37119.jhtml)；数据源见[深圳市政府数据开放平台](https://opendata.sz.gov.cn/)与[高德开放平台](https://lbs.amap.com/)。
