# 数据来源

- 深圳市政府数据开放平台：[共享单车企业每日订单表所在平台](https://opendata.sz.gov.cn/)。研究使用的日期为 2021-08-20 至 2021-08-28；原始接口抓取范围另含 08-29、08-30，但这两天因返回量异常偏低未进入主分析。
- 高德开放平台：[Web 服务与 POI 数据](https://lbs.amap.com/)。POI 按类型归并后映射到 H3 网格。

原始订单、POI 点表、接口密钥和大型中间面板没有复制到公开仓库。论文中公开的是聚合统计与模型结果；`../results/` 只保留小型汇总表。数据访问权限、调用配额和当前接口响应需要由复现者自行核实。
